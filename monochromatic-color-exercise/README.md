# Monochromatic Color Exercise

## Version 1
Phối màu đơn tông theo yêu cầu bài:
- Primary: #00ADEE
- Background: #00BFF2
- Content: #8DD7F7

Luyện tập sử dụng màu sắc và phối màu đơn tông trong thiết kế website.
