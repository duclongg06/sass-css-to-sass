# Newsletter Color Exercise

## Mục tiêu
Thực hành phối màu newsletter bằng Adobe Color
và áp dụng palette vào website Bootstrap responsive.

## Version 1

Version 1 sử dụng palette lấy cảm hứng từ Adobe Color,
với tông xanh dương chủ đạo.

Primary: #2563EB
Secondary: #1D4ED8
Accent: #38BDF8
Light Background: #EFF6FF
Text: #000000

## Version 2

Version 2 sử dụng palette tông tím,
được xây dựng theo nguyên tắc phối màu đơn sắc/monochromatic.

Primary: #7C3AED
Secondary: #6D28D9
Accent: #A78BFA
Light Background: #F5F3FF
Text: #000000

## Công nghệ

- HTML5
- CSS3
- Bootstrap 5.3.3
- CSS Variables
- Adobe Color

## Responsive

Đã kiểm tra desktop, tablet và mobile.
